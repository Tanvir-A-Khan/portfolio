# Profile icons

- GitHub, LinkedIn, WhatsApp, and email: the installed `@ant-design/icons-svg` library (MIT); standalone SVG namespace and display colors added.
- Codeforces, CodeChef, and HackerRank: https://github.com/simple-icons/simple-icons/tree/develop/icons (CC0), with display colors added.
- VJudge: original website favicon, https://vjudge.net/static/favicon.ico.

Icons are stored locally; link text remains visible and supplies accessible names.
